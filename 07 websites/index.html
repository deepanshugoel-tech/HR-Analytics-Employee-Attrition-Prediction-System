Model Selection Insight

Business interpretation of the model comparison.

Logistic Regression achieved the highest accuracy of 88.44% and the highest ROC-AUC of 0.7917. It also achieved the highest recall and F1-score among the three evaluated models.

Random Forest achieved the highest precision of 80.00%. However, its recall was only 10.26%, meaning that it missed many employees who actually left the organization.

Decision Tree produced the lowest overall performance in the current experiment, with an accuracy of 77.55% and ROC-AUC of 0.5231.

Based on the current evaluation, Logistic Regression provides the best overall balance for identifying potential employee attrition, while Random Forest remains useful when precision is the primary requirement.

SQL EXAMPLE

Department Attrition Analysis 

SELECT
    Department,
    COUNT(*) AS Total_Employees,
    SUM(CASE
        WHEN Attrition = 'Yes' THEN 1
        ELSE 0
    END) AS Employees_Left
FROM employees
GROUP BY Department
ORDER BY Employees_Left DESC;

PROJECT INFORMATION

About the Project

AI-Powered HR Analytics & Employee Attrition Prediction System.

🎯 Project Objective

The main objective of this project is to analyze employee data, understand attrition patterns and use machine learning to predict potential employee attrition.

📊 Dataset

IBM HR Analytics Employee Attrition dataset containing 1,470 employee records and multiple workforce-related features.

🛠 Technologies Used

Python Pandas NumPy Scikit-learn MySQL SQL Power BI HTML CSS JavaScript FastAPI

🧠 Machine Learning

The project evaluates Logistic Regression, Decision Tree and Random Forest using Accuracy, Precision, Recall, F1 Score and ROC-AUC metrics. Logistic Regression currently provides the best overall balance among the evaluated models.
