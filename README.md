## 📌 Project Overview

The **AI-Powered HR Analytics & Employee Attrition Prediction System** is a complete HR Analytics solution that helps organizations analyze employee data and predict employee attrition using Machine Learning. The project combines **Python, Machine Learning, MySQL, SQL, and Microsoft Power BI** to provide data-driven insights for Human Resource management.

This project enables HR professionals to identify employees who are at risk of leaving the organization and supports better workforce planning and strategic decision-making.
